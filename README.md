Proyek Kartu Profil — Aplikasi Android

Deskripsi Projek

Proyek Kartu Profil merupakan aplikasi berbasis Android yang dibuat menggunakan bahasa pemrograman Kotlin. Aplikasi ini digunakan untuk memasukkan dan menampilkan informasi profil pengguna.

Fitur Aplikasi

- Input nama pengguna.
- Input email.
- Menampilkan informasi profil.
- Tombol Simpan untuk menyimpan data.
- Tombol Batal untuk menghapus input.
- Navigasi ke halaman kedua.
- Menampilkan informasi menggunakan Toast.

Teknologi yang Digunakan

- Android Studio
- Kotlin
- XML Layout
- Android SDK
- Gradle

Struktur Projek

projek-kartu-profil/
├── app/
├── gradle/
├── screenshot/
├── .gitignore
├── README.md
├── build.gradle
├── gradle.properties
├── gradlew
└── settings.gradle

Cara Menjalankan Aplikasi

1. Download atau clone repository.
2. Buka projek menggunakan Android Studio.
3. Tunggu proses Gradle selesai.
4. Hubungkan perangkat Android atau gunakan emulator.
5. Jalankan aplikasi dengan menekan tombol Run.
